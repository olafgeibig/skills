# OpenCode Go plan facts (verified 2026-10-20)

- **Two tiers: Go $10/month and Go Plus $40/month** (Go Plus announced 2026-09-28). Same models, same token prices; the monthly caps grow by 2x-8x depending on the model (verified factors: hybrid `hy3` and several $15-tier models 4x, `glm-5.3-flash`/`minimax-m3` 3x, MiMo and `deepseek-v4.1-flash` 2x, `glm-5.3` 8x), and request limits scale with them. Never claim "only one tier" — the docs page renders the plans as TABS (`Go | Go Plus`), so a naive text extraction reads only the active tab. Fetch the raw HTML and read every `<table>`.
- **Capacity is per model.** Every model carries its own rolling bucket (monthly usage caps $15/$30/$60 plus 5-hour and weekly sub-limits). Spreading roles across models is the only way to stretch the subscription; one model cannot borrow another's bucket.
- **Overflow lever, priced at the plan's peak row:** top up Zen credit and enable "Use balance" — after Go limits are hit, requests fall back to the Zen balance (pay-per-token, full Zen catalog) instead of blocking. The Zen catalogue prices DeepSeek V4.1 Flash at $0.30/$1.20 (cached $0.006) — exactly the Go peak row, 2× the off-peak plan rate, so overflow is a bridge for days, not a way to run a month.
- **Cheaper than overflow: the direct key.** DeepSeek's own API serves the same model as `deepseek-flash` (= `deepseek-v4.1-flash`) at the plan's off-peak rate $0.15/$0.60. When the plan's DeepSeek bucket runs dry, a `fallback_providers` entry `{provider: deepseek, model: deepseek-flash}` adds capacity pay-per-token with no fixed cost — the pattern for any plan model whose vendor also sells it directly.
- **MiniMax M3 is part of the plan** ($0.30/$1.20, $60 bucket, ~16k requests/month), so a separate MiniMax subscription is only needed for non-Hermes use.
- **Two auth shapes under one base URL** (`https://opencode.ai/zen/go/v1`): `/chat/completions` (OpenAI-compatible, `Authorization: Bearer`) for GLM/MiMo/DeepSeek/Hy, `/messages` (Anthropic shape, `x-api-key` + `anthropic-version`) for MiniMax and Qwen. See `live-provider-probes.md`.
- The lineup churns between refreshes — re-fetch the keyed `/models` list before quoting model IDs, and prefer the keyed answer over the public catalogue (superset). Source of truth for the researched model table, caps and vision probes: vault `akademeia`, `area/ai/opencode-go-models.md`.
